# FoodIndustry — legacy prototype (superseded)

This folder contains the original static HTML/CDN prototype. It has been
replaced by the real full-stack app in [../backend](../backend) and
[../frontend](../frontend) — see the top-level [README.md](../README.md).

Note: as originally written, this prototype didn't actually run in a
browser — its `<script src="https://unpkg.com">` tags were missing package
paths, so React/ReactDOM/Babel/Tailwind never loaded. It's kept here for
reference only (component structure, mock data shape).
